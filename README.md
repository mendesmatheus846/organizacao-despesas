# Organização de Despesas Pessoais

## Objetivo
Criar um programa em C que organize despesas pessoais usando os algoritmos Bubble Sort e Quick Sort.

## Situação-problema
Uma pessoa possui várias despesas, como aluguel, mercado e internet. Organizar esses gastos do menor para o maior facilita a visualização e o controle financeiro.

## Como executar
1. Abra o arquivo `organizacao_despesas.c` no VS Code.
2. Compile o programa com o GCC.
3. Execute o programa pelo terminal.

## Bubble Sort
Compara valores vizinhos e troca suas posições quando estão fora de ordem.

## Quick Sort
Escolhe um valor como pivô, separa os valores menores e maiores e repete o processo até ordenar a lista.

O sistema permite cadastrar despesas pessoais e organizá-las em ordem crescente de valor utilizando os algoritmos Bubble Sort e Quick Sort
